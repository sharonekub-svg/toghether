# קבצי מדיה לאתר

הניחו כאן את קבצי התמונות של האתר. שמות הקבצים שהאתר מחפש:

## לוגו (הלוגו שיעל עיצבה)
- **`logo.png`** — הלוגו שמופיע בכותרת ובפוטר, במקום ראשי התיבות "ר״ק".
  מומלץ קובץ מרובע/שקוף (PNG או SVG). אם רוצים SVG, שמרו כ-`logo.png`
  או עדכנו את הנתיב ב-`index.html` (מחרוזת `assets/logo.png`).
  אם הקובץ חסר — האתר מציג אוטומטית את ראשי התיבות "ר״ק" כגיבוי.

## תמונות פורטרט
- **`roey-hero.jpg`** — התמונה הגדולה באזור הפתיחה (Hero).
- **`roey-portrait.jpg`** — התמונה באזור "אודות".

הערה: תמונה של עו״ד רועי קובובסקי אינה מוצגת באזור "צור קשר" — לפי הבקשה.
