# אתר עו״ד רועי קובובסקי

אתר תדמית למשרד רועי קובובסקי, עורכי דין — משפט מנהלי, דיני מכרזים וליטיגציה.
כולל עמוד "צרו קשר" עם טופס פנייה והגשת מועמדות, ועמוד תקנון ומדיניות פרטיות.
אתר סטטי (HTML/CSS/JS), ללא שלב build, מוכן לפריסה.

## מבנה

| קובץ | תיאור |
|------|-------|
| `index.html`   | עמוד יחיד: Hero, אודות, קריירה (תחומי עיסוק + סוגי תיקים), צרו קשר |
| `privacy.html` | תקנון האתר ומדיניות הפרטיות |
| `styles.css`   | עיצוב מלא, RTL, רספונסיבי (מונוכרום שחור-לבן) |
| `app.js`       | ניווט, אנימציות גלילה דו-כיווניות, פרלקסה, v-card וטיפול בטופס |
| `config.js`    | הגדרות: חיבור ל-Supabase, טלפון ודוא״ל |
| `vercel.json`  | כותרות אבטחה ו-clean URLs לפריסה ב-Vercel |

## הקטגוריות באתר

- **אודות** — פרופיל עו״ד קובובסקי בסגנון משרד מוביל, עם ביוגרפיה, דוא״ל ו-v-card.
- **קריירה** — במה המשרד עוסק: תחומי עיסוק (משפט מנהלי, מכרזים, ליטיגציה) וסוגי
  התיקים האופייניים — מאוחדים לעמוד אחד.
- **צרו קשר** — פרטי המשרד וטופס פנייה / הגשת מועמדות.

## הטופס "צרו קשר"

לטופס שני מצבים: **ייעוץ / פנייה כללית** ו**הגשת מועמדות לעבודה**. שליחה מחייבת
אישור מדיניות הפרטיות (checkbox). הפניות נשמרות בטבלה `roey_leads` ב-Supabase
(הרשאת הוספה בלבד מהדפדפן, דרך Row Level Security). אם השמירה נכשלת או שאין
חיבור — נפתחת תוכנת הדוא״ל עם הפרטים לכתובת `fallbackEmail` שב-`config.js`.

### צפייה בפניות שהתקבלו

דרך לוח הבקרה של Supabase → Table Editor → `roey_leads`. מהדפדפן של המבקרים
אי אפשר לקרוא אותן — רק להוסיף.
