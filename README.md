# תוגדאו 🎫 — כרטיס יד שנייה. ביטחון יד ראשונה.

אפליקציית ווב (מובייל-פרסט, עברית RTL) לקנייה ומכירה של כרטיסים יד-שנייה
במחיר הנקוב בלבד — עם כסף בנאמנות, מוכרים מאומתים והחזר מלא בלחיצה אחת.
מבוססת על ה-GAMEPLAN המלא של המיזם.

## מה יש בפנים

| קובץ | מה זה |
|---|---|
| `index.html` + `styles.css` + `app.js` | האפליקציה עצמה — סטטית, בלי build, עולה ל-Vercel כמו שהיא |
| `config.js` | חיבור ל-Supabase (ריק = מצב דמו עם נתונים מובנים) |
| `supabase/migrations/0001_togdao_init.sql` | הסכמה המלאה: פרופילים, אירועים, מודעות, כספת כרטיסים, הזמנות (אסקרו), מחלוקות, רשימות המתנה, לוג ביקורת — כולל RLS |
| `DESIGN_PROMPT.md` | פרומט מוכן להדבקה בכלי דיזיין AI |

## הפיצ'רים (מהגרסה הקודמת של התוכנית — כולם בפנים)

- 🔒 **אסקרו** — הכסף מוחזק עד יומיים אחרי האירוע; ציר זמן מלא בצ'קאאוט ובארנק
- ⚖️ **תקרת מחיר נקוב** — סליידר שחסום מעל הנקוב (סעיף 194א)
- ✔ **תגי SAFE / מאומת** — כולל הסבר "ברקוד חדש הונפק"
- 🪪 **מוכרים מאומתים (KYC)** — טלפון, ת"ז, חשבון בנק תואם + ציון אמון
- 📄 **העלאת כרטיס לכספת + OCR** — כולל בדיקת כפילות ברקוד (hash)
- 💳 **צ'קאאוט** — מחיר ודמי שירות (7.5%, מינ' ₪15) בשתי שורות נפרדות; Apple/Google Pay, כרטיס, Bit
- 👛 **ארנק** — קניתי / מכרתי / התראות; QR נעול עד יום האירוע
- 🚨 **"סורבתי בכניסה"** — דיווח בלחיצה עם חותמת מיקום+זמן והחזר מהנאמנות
- ⏰ **רשימת המתנה** — התראה + חלון קנייה של 10 דקות (כולל הדגמה חיה)
- 📣 **קטלוג אירועים** — חיפוש, קטגוריות, SOLD OUT

## פריסה ל-Vercel (2 דקות)

יש לך כבר חשבון Vercel (הפרויקט `hit` רץ שם), אז:

1. נכנסים אל <https://vercel.com/new>
2. בוחרים **Import Git Repository** → `sharonekub-svg/toghether`
3. Framework: **Other** · Build command: ריק · Output directory: ריק (root)
4. **Deploy**. זהו — האתר באוויר.

כל push לענף הראשי יתפרס אוטומטית.

## חיבור Supabase

> ⚠️ החשבון החינמי שלך מלא (2 פרויקטים: `spontani` + `seventeen`).
> כדי ליצור את פרויקט `togdao` צריך למחוק/להשהות אחד מהם או לשדרג.

אחרי שיש פרויקט:

1. ב-SQL Editor מריצים את `supabase/migrations/0001_togdao_init.sql`
2. מעתיקים מ-Settings → API את ה-URL ואת ה-publishable key
3. מדביקים אותם ב-`config.js` — והאפליקציה עוברת אוטומטית מדמו לדאטה אמיתי
