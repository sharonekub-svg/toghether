# אתר עו״ד רועי קובובסקי

אתר תדמית למשרד עצמאי למשפט מנהלי, דיני מכרזים וליטיגציה מנהלית — כולל עמוד
"צרו קשר" עם טופס פנייה והגשת מועמדות לעבודה. אתר סטטי (HTML/CSS/JS), ללא שלב
build, מוכן לפריסה.

## מבנה

| קובץ | תיאור |
|------|-------|
| `index.html` | עמוד יחיד עם כל החלקים: Hero, רצועת הכרה, אודות, תחומי עיסוק, סוגי התיקים, צרו קשר |
| `styles.css` | עיצוב מלא, RTL, רספונסיבי (מונוכרום שחור-לבן) |
| `app.js`     | ניווט, אנימציות גלילה, וטיפול בטופס |
| `config.js`  | הגדרות: חיבור ל-Supabase, טלפון ודוא״ל |
| `vercel.json`| כותרות אבטחה ו-clean URLs לפריסה ב-Vercel |

## הטופס "צרו קשר"

לטופס שני מצבים:

1. **ייעוץ / פנייה כללית** — שם, אימייל, טלפון והודעה.
2. **הגשת מועמדות לעבודה** — שם, אימייל, טלפון, ו"למה אתם מתאימים לעבודה".

הפניות נשמרות בטבלה `roey_leads` ב-Supabase (הרשאת הוספה בלבד מהדפדפן, דרך
Row Level Security). אם השמירה נכשלת או שאין חיבור — נפתחת אוטומטית תוכנת הדוא״ל
עם הפרטים לכתובת שב-`config.js` (`fallbackEmail`).

### צפייה בפניות שהתקבלו

הפניות נצפות דרך לוח הבקרה של Supabase → Table Editor → `roey_leads`
(או בשאילתת SQL). מהדפדפן של המבקרים אי אפשר לקרוא אותן — רק להוסיף.
