# תוגדאו 🏢 — הבניין מזמין ביחד

אפליקציית ווב (מובייל-פרסט, עברית RTL) להזמנות משותפות של שכני בניין:
שכן פותח סל משותף מחנות, כל אחד מוסיף את הפריטים שלו, המשלוח מתחלק בין
כולם (וחינם מעל יעד), כל אחד משלם רק על שלו — והכסף מוחזק באסקרו עד
שהחבילה מגיעה לבניין ופותח ההזמנה מאשר מסירה.

זו גרסת ווב בסגנון חדש של הרעיון מ-**שכנא** (`shakana`), עם כל הפיצ'רים
של הגרסה הקודמת — בקובץ סטטי אחד, בלי build.

## מה יש בפנים

| קובץ | מה זה |
|---|---|
| `index.html` + `styles.css` + `app.js` | האפליקציה — סטטית, בלי build, עולה ל-Vercel כמו שהיא |
| `config.js` | חיבור ל-Supabase (ריק = מצב דמו עם נתונים מובנים ב-localStorage) |
| `supabase/migrations/0001_togdao_init.sql` | הסכמה: בניינים, פרופילים, חנויות, מוצרים, הזמנות, משתתפים, פריטים, הזמנות-לינק, תשלומים (אסקרו) — כולל RLS ו-seed |
| `DESIGN_PROMPT.md` | פרומט מוכן להדבקה בכלי דיזיין AI |

## הפיצ'רים (מהגרסה הקודמת — כולם בפנים)

- 🧺 **סל משותף לבניין** — הזמנה קבוצתית אחת לכל חנות, כל שכן מוסיף את שלו
- 📊 **בר משלוח חינם** — מתמלא עם כל פריט; חינם מעל ₪400
- ⏳ **טיימר סל חי** — ספירה לאחור; כשמסתיים הסל ננעל והחנות מטפלת
- 👋 **הצטרפות דרך קוד / לינק** — כולל שיתוף בוואטסאפ ("מסך הצטרפות")
- 💳 **תשלום מפוצל + אסקרו** — כל אחד משלם על שלו + חלק שווה במשלוח; הכסף מוחזק (manual capture) עד אישור מסירה
- 🙈 **פריט פרטי** — שכנים רואים "פריט פרטי", לא מה הוא
- 📦 **ציר סטטוס** — איסוף → התקבלה → באריזה → מוכנה → נמסרה
- 🏬 **מסך חנות (דמו)** — הבניין כהזמנה מרוכזת אחת עם רשימת ליקוט
- 👥 **סימולציה חיה** — שכנים "מצטרפים" ומוסיפים פריטים בזמן אמת
- 🔔 **פיד "קורה בבניין"**, פרופיל, הגדרות התראות (WhatsApp)

הכול נשמר ב-localStorage, אז הזמנות שאתם פותחים נשארות בין רענונים.

## עיצוב

"שכונה בניאון בלילה" — רקע כחול-דיו כהה, ליים חשמלי כמבטא, מוטיב חלונות
דירה מוארים בכותרת. פונט Heebo, לוגו ב-Secular One, RTL מלא.

## פריסה ל-Vercel (2 דקות)

יש לך כבר חשבון Vercel, אז:

1. נכנסים אל <https://vercel.com/new>
2. בוחרים **Import Git Repository** → `sharonekub-svg/toghether`
3. Framework: **Other** · Build command: ריק · Output directory: ריק (root)
4. **Deploy**. זהו — האתר באוויר.

כל push לענף יתפרס אוטומטית.

## חיבור Supabase

> ⚠️ החשבון החינמי שלך מלא (2 פרויקטים: `spontani` + `seventeen`).
> כדי ליצור פרויקט `togdao` צריך למחוק/להשהות אחד מהם או לשדרג.

אחרי שיש פרויקט:

1. ב-SQL Editor מריצים את `supabase/migrations/0001_togdao_init.sql`
2. מעתיקים מ-Settings → API את ה-URL ואת ה-publishable key
3. מדביקים אותם ב-`config.js` — והקטלוג עובר לדאטה אמיתי

בגרסת ווב זו התשלומים מודגמים; ב-shakana המקורי האסקרו רץ על Stripe
Connect עם manual capture ו-Edge Functions.
